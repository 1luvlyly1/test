Entity mẫu (draw.io flowchart)

16 loại entity agent được phép dùng. Trường type trong JSON spec phải là một trong các mã dưới đây.

start

Bắt đầu

draw.io: Terminator

Điểm khởi đầu quy trình. Thường có đúng 1.

end

Kết thúc

draw.io: Terminator

Điểm kết thúc (có thể nhiều: hoàn tất, từ chối, huỷ...).

process

Xử lý / Hành động

draw.io: Process

Một bước công việc, hành động do người hoặc hệ thống thực hiện.

decision

Điều kiện

draw.io: Decision

Câu hỏi Có/Không hoặc rẽ nhiều nhánh; mỗi nhánh ra phải có nhãn.

io

Nhập / Xuất dữ liệu

draw.io: Data

Dữ liệu vào/ra: form, file, API request/response.

document

Tài liệu

draw.io: Document

Văn bản, hợp đồng, báo cáo, chứng từ được tạo hoặc dùng.

database

Cơ sở dữ liệu

draw.io: Database

Lưu trữ / truy vấn dữ liệu: CRM, core banking, data lake.

subprocess

Quy trình con

draw.io: Predefined Process

Một quy trình đã định nghĩa ở nơi khác (gọi lại).

manual_input

Nhập thủ công

draw.io: Manual Input

Nhân viên/khách hàng nhập liệu bằng tay.

manual_op

Thao tác thủ công

draw.io: Manual Operation

Bước làm thủ công, không tự động hoá (ký, kiểm đếm...).

preparation

Chuẩn bị

draw.io: Preparation

Khởi tạo, chuẩn bị điều kiện, cấu hình trước khi xử lý.

delay

Chờ / Trì hoãn

draw.io: Delay

Thời gian chờ, SLA, hàng đợi phê duyệt.

display

Hiển thị

draw.io: Display

Thông tin hiển thị trên màn hình / app / dashboard.

event

Sự kiện

draw.io: Ellipse

Sự kiện, thông báo, trigger (email, SMS, webhook).

connector

Điểm nối

draw.io: On-page Reference

Điểm nối/nhảy (A, B...) khi luồng quá xa. Hạn chế dùng.

note

Ghi chú

draw.io: Note

Chú thích bổ sung, nối bằng cạnh style=dotted.
